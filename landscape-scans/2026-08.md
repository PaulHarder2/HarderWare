### 3. CodeRabbit Post-Merge Actions — auto-file Jira tickets on PR merge

**What changed.** CodeRabbit now executes automated actions when a PR merges into the default branch. Supported: file a Jira ticket, open a GitHub Issue, append a changelog entry, post a Slack summary. Each action is previewed as a checkbox in the PR walkthrough; CodeRabbit decides which are applicable to the diff.

**Why it matters.** Automated Jira ticket creation on merge could reduce manual overhead for the WX-ticket workflow.

**Cost to add.** Included in existing CodeRabbit Pro subscription.

**Recommended next step.** Check the Post-Merge Actions section in CodeRabbit repo settings and configure Jira ticket creation.
